# vibe-stick 사용법

키보드에 손대지 않고 Claude Code에 말로 지시하는 버튼입니다.

## 처음 한 번: 맥과 짝 맺기

1. 기기를 켭니다(왼쪽 전원 버튼). 화면에 **PAIR ME** 가 보입니다.
2. 맥의 시스템 설정 → Bluetooth 에서 `vibe-stick` 옆의 "연결"을 누릅니다.
3. 화면이 **HI!** 로 바뀌면 끝입니다(위쪽에 초록색 READY). "키보드 설정 지원" 창이 뜨면 닫으세요.

다음부터는 기기를 켜면 스스로 연결됩니다.

## 조작

VS Code의 Claude 입력창을 한 번 클릭해 둔 상태에서 씁니다.

| 조작 | 동작 |
|---|---|
| 조이스틱 **누르기** | 말하기. **한 번 누르면 녹음이 켜지고, 다시 누르면 꺼집니다.** 누른 채 버틸 필요가 없습니다(딸깍 한 번이면 됩니다). 누르는 순간 조이스틱의 작은 불이 켜집니다 |
| **앞 큰 버튼** | 확인 (보내기 · 승인 · 선택 확정). 화면에 따라 뜻이 달라집니다 — 아래 표 참고 |
| **옆 버튼** (오른쪽 옆면) | 취소 · 거부 · 목록 닫기 (Claude가 일하는 중에 누르면 작업이 멈춥니다). 1초에 한 번만 동작합니다 |
| 조이스틱 **오른쪽 / 왼쪽** | VS Code의 **다음 창 / 이전 창**으로 바로 이동(목록이 뜨지 않습니다). 창이 여러 개면 한 번 더 밀면 그다음 창 |
| 조이스틱 **위·아래** | 선택지 고르기(허락 창, 질문 창 등) |

알아둘 점
- 앞 버튼과 옆 버튼은 **뗄 때** 동작합니다.
- 조이스틱을 누르고 있는 동안에는 앞 버튼·옆 버튼이 동작하지 않습니다.
- 말하기를 켜면 기기 화면에 **TALK** 가 계속 떠 있습니다. 다만 기기는 컴퓨터가 녹음을 스스로 끈 것(15초 조용할 때)을 알 수 없습니다. 헷갈리면 **컴퓨터 화면의 마이크 표시**가 기준입니다. 앞 큰 버튼으로 한 번 보내면 기기 화면도 다시 맞습니다.
- 조이스틱을 아주 빠르게 두 번 누르면(0.25초 안) 두 번째는 무시합니다(켜자마자 꺼지는 것을 막기 위해).
- 조이스틱은 끝까지 밀어야 인정됩니다. 누를 때 살짝 기울어지는 것은 무시합니다.

### 말로 지시하는 순서

1. 조이스틱을 한 번 누릅니다(딸깍). 녹음이 켜집니다.
2. 말합니다. 말한 내용이 컴퓨터 화면의 입력창에 글로 나타납니다.
3. **글이 다 나타난 것을 보고** 조이스틱을 한 번 더 누릅니다. 녹음이 꺼집니다.
4. 앞 큰 버튼을 눌러 보냅니다.

끄는 것을 잊어도 15초 동안 말이 없으면 스스로 꺼집니다(길어도 2분).
3번을 건너뛰고 바로 앞 큰 버튼을 누르면 녹음을 끄면서 그때까지의 글을 곧바로 보냅니다 — 글이 다 나타난 뒤에만 쓰세요.

글이 잘못 받아써졌을 때: 기기로는 지울 수 없습니다. 그대로 보낸 뒤 말로 고쳐 달라고 하거나, 키보드로 지웁니다.

### 앞 큰 버튼은 화면에 따라 뜻이 달라집니다

기기는 컴퓨터 화면을 알지 못합니다. **누르기 전에 컴퓨터 화면을 보세요.**

| 컴퓨터 화면 | 앞 큰 버튼을 누르면 |
|---|---|
| 입력창에 글이 있음 | 그 글을 Claude에게 보냅니다 |
| 입력창이 비어 있음 | 아무 일도 없습니다 |
| 녹음이 켜져 있음 | 녹음을 끄고, 그때까지 나타난 글을 바로 보냅니다 |
| Claude가 허락을 구하는 창 | 지금 테두리가 있는 선택지를 고릅니다(처음에는 맨 위 = 허락) |
| Claude가 계획을 보여주고 승인을 구하는 창 | 계획을 승인하고, 이후 수정을 묻지 않고 진행하게 됩니다 |
| Claude가 질문하는 창 | 지금 선택지를 고릅니다. 한 번 더 누르면 답을 제출합니다 |

### Claude가 허락을 구할 때 (영어로 뜹니다)

| 화면의 글 | 뜻 | 고르는 법 |
|---|---|---|
| Yes | 이번 한 번만 허락 | 앞 큰 버튼 |
| Yes, allow all edits this session / Yes, and don't ask again | **앞으로 계속 허락**(다시 묻지 않음) | 조이스틱 아래로 한 번 → 앞 큰 버튼 |
| No | 거부 | 옆 버튼 |

"앞으로 계속 허락"은 되돌리기 번거로우니, 조이스틱을 실수로 아래로 민 뒤에는 앞 버튼을 누르기 전에 화면을 확인하세요.

### 조심할 것 세 가지

| 하면 안 되는 것 | 이유 |
|---|---|
| 입력창이 비어 있을 때 조이스틱을 **위로** 민 뒤 앞 버튼 | 위로 밀면 바로 전에 보낸 지시가 입력창에 다시 나타납니다. 그대로 앞 버튼을 누르면 **같은 지시가 또 전송**됩니다. 지시가 나타났다면 조이스틱을 아래로 두 번 밀어 되돌리세요 |
| **파일을 보는 창(편집기)을 클릭한 뒤** 기기 사용 | 조이스틱 누름과 앞 버튼이 Claude가 아니라 파일로 들어가 **파일의 글자가 바뀔 수 있습니다.** 기기를 쓰기 전에 Claude 입력창을 한 번 클릭하세요 |
| 옆 버튼을 빠르게 여러 번 누르기 | Claude에는 "빠르게 두 번 = 되감기 창 열기" 기능이 있어, 이어서 앞 버튼을 누르면 Claude가 고친 파일이 되돌려집니다. 기기가 1초에 한 번만 보내도록 막고 있지만, "Rewind"라고 쓰인 창이 보이면 옆 버튼으로 닫으세요 |

### 창을 바꿔서 지시하기

1. 조이스틱을 오른쪽으로 밉니다 → 다음 VS Code 창으로 바로 넘어갑니다(왼쪽은 이전 창).
2. 조이스틱을 눌러 말합니다.

맥의 기본 기능("같은 앱의 다음 창으로", ⌘`)을 쓰므로 VS Code가 맨 앞에 있을 때 VS Code 창끼리 넘어갑니다. 다른 앱이 맨 앞이면 그 앱의 창이 넘어갑니다.

## 화면

![화면 모음](design/screens.png)

위쪽 검은 띠에는 연결 상태(READY 초록 / SEARCH·LINKING·PAIR 노랑)와 배터리가, 가운데에는 캐릭터가, 아래 말풍선에는 지금 상태나 방금 한 동작이 영어 낱말로 나옵니다.

| 화면 글자 | 뜻 | 언제 |
|---|---|---|
| HI! | 준비됨 | 연결되어 기다리는 중 |
| TALK | 말하기 | 조이스틱을 눌러 말하기를 켠 동안 계속 |
| OK! | 확인 | 앞 큰 버튼(보내기·허락·선택) |
| NOPE | 취소 | 옆 버튼(취소·거부) |
| UP / DOWN | 위 / 아래 | 조이스틱 위·아래 |
| NEXT / BACK | 다음 창 / 이전 창 | 조이스틱 오른쪽·왼쪽 |
| PAIR ME | 연결해 주세요 | 짝 맺은 컴퓨터가 없음 |
| MAC? | 컴퓨터를 찾는 중 | 짝 맺은 컴퓨터가 꺼져 있거나 멀리 있음 |
| WAIT | 잠깐만요 | 연결하는 중 |
| NO LINK | 못 보냄 | 연결이 없을 때 버튼을 누름 |
| BYE! | 짝 정보를 지움 | 앞 + 옆 버튼 3초 |
| OOPS | 지우지 못함 | 짝 초기화 실패 |
| (맨 아래 띠) NO STICK | 조이스틱 없음 | 조이스틱이 빠졌거나 읽히지 않음 |

TALK 는 말하기가 켜져 있는 동안 남아 있고, 나머지 동작 화면은 1.5초쯤 보였다가 대기 화면으로 돌아갑니다.

기기는 자기가 보낸 것만 보여줍니다. Claude가 지금 일하고 있는지는 컴퓨터 화면에서 확인하세요.

배터리로 쓸 때는 30초 동안 조작이 없으면 화면이 어두워집니다. 아무 버튼이나 누르면 다시 밝아지고, 그 누름도 그대로 동작합니다. USB를 꽂아 두면 어두워지지 않습니다.

## 이럴 때는

| 상황 | 방법 |
|---|---|
| 눌러도 반응이 없다 | Claude 입력창을 한 번 클릭합니다. VS Code가 맨 앞에 있어야 합니다 |
| 화면에 NO LINK 또는 MAC? | 맥의 Bluetooth 가 켜져 있는지 확인합니다 |
| 맨 아래에 NO STICK | 조이스틱을 뽑았다 다시 꽂습니다(켜진 채 꽂아도 5초 안에 인식합니다). 없어도 앞 버튼을 0.6초 이상 누르면 말하기가 됩니다 |
| 다른 컴퓨터에 연결하고 싶다 | ① 원래 컴퓨터의 Bluetooth 설정에서 `vibe-stick` 을 지웁니다(또는 그 컴퓨터의 Bluetooth 를 끕니다). ② 기기의 앞 버튼과 옆 버튼을 함께 3초 누릅니다. BYE! 가 뜨고 기기가 스스로 다시 켜져 PAIR ME 가 됩니다. ③ 새 컴퓨터에서 연결합니다 |
| OOPS 가 뜬다(짝 초기화 실패) | 한 번 더 시도합니다. 계속 실패하면 기기를 껐다 켠 뒤 다시 합니다 |
| 화면이 계속 WAIT 이다 | 30초 기다리면 스스로 끊고 다시 시도합니다. 반복되면 컴퓨터의 Bluetooth 설정에서 `vibe-stick` 을 지우고 다시 연결합니다 |
| 컴퓨터에서 `vibe-stick` 을 지웠는데 다시 안 붙는다(MAC? 나 WAIT 에서 멈춤) | 기기 쪽에는 옛 짝 정보가 남아 있어 새 짝을 거부합니다. 앞 버튼과 옆 버튼을 함께 3초 눌러(BYE!) 기기 쪽도 지운 뒤, PAIR ME 가 뜨면 다시 연결합니다 |
| 화면이 멈췄다(눌러도 그대로) 또는 켜지지 않는다 | 조이스틱을 뽑고 전원 버튼으로 껐다 켭니다. 켜진 뒤 조이스틱을 다시 꽂으면 됩니다 |
| 배터리가 빨리 닳는다 | 배터리가 작습니다. 책상에서는 USB를 꽂아 두세요 |
